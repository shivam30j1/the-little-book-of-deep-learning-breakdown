# Machine Learning

Deep learning is a subset of machine learning in that the purpose remains the same: learning representations from a given dataset _without explicitly programmed_ rules. It is an important and distinct subset because it follows an approach where the architecture is set up such that learned, intermediate outputs at a specific level in the architecture flow as input to the next level. The final output is connected to the original input through a series of intermediate connections, resulting in a “deep” (er) form of machine learning.

Deep learning has now been shown to achieve greater performance due to its _modularity, versatility, and scalability_.
•	Modularity: A deep architecture can be broken into smaller pieces, which can further be broken into yet smaller _pieces_. They are customizable, and they _stack_. Systems-thinking helps here: deep learning can be thought of as an _assembly line_. This becomes _extremely_ powerful: customizations can be endless and each piece can be integrated to learn a _specific, abstract_ representation of the data.

•	Versatility: Deep learning is _very_ versatile. Multiple important use-cases are detailed in the book on text, vision, and sound signals. What is elegant is how the architecture is engineered with _structural constraints_ such that solving the task becomes the easiest — or sometimes the only — way for the network to satisfy the training objective. Intelligence emerges because of the constraints built into the system. This goes back to the power of modularity: constraints can be imposed through several pieces interacting together such that the solution is a _natural consequence_ of training.

•	Scalability: Deep architectures can be scaled arbitrarily across data, model components, and compute. Since models are successive components of mappings, scaling results in far greater _sophistication_ of learning than possible with conventional models.

# 1.1	Learning from data
At its core, machine learning is about connecting a signal x to a quantity y. Consider, for example, a multidimensional image of a license plate from which one wants to predict the string of letters written on the plate. Consider then a dataset x that contains n such images and corresponding strings, for a total n pairs of (x, y).

It is prohibitively complex in most situations to relate x to y analytically (a precise “do this to x to get the y”). This is especially true when x is a high-dimensional signal. What is possible is to design a mathematical model that depends on the values of parameters w, such that optimal values of all w’s (w*) result in a model that predicts a good value for y given x, for each of the n pairs. Goodness is formalized through a loss function, which is typically minimized to find optimal values of w*. Loss serves as a proxy for how _good_ the model currently is and how much _better_ it is becoming after each training pass.

Designing, under constraints, such a model f is the crux of machine (and deep) learning. The trainable parameters w* are referred to as weights. Certain other values impact model behavior and are known as hyperparameters. These are usually set at the architectural level _before_ training begins and may be modulated somehow, but through techniques distinct than the ones used to modulate w*. Since they are set prior to training and their values directly impact performance, hyperparameters are tuned based on prior experience, domain expertise, resource constraints, etc.

E.g. w* = weights of a layer
     hyperparameter = number of neurons in a layer
