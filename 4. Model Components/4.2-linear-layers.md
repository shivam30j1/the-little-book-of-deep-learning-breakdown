# 4.2 Linear layers
Linear layers are the most common and the most important type of layer. The operation is technically _affine_, where a constant bias is added to the linear transformation. Regardless, they are called _linear_ layers.

# Fully connected layers
A fully connected linear layer applies a linear (technically affine) operation to a feature vector. It creates a new feature vector as a _weighted combination_ of the original feature vector. Given a feature vector of dimensionality $D$, it creates a feature vector of dimensionality $D'$, where $D$ _may or may not equal_ $D'$. Formally, for an input $X$ of dimension $D_1 \times \cdots \times D_K \times D$, it applies an affine transformation using a weight matrix $W$ and a bias vector $b$ such that:

$$
\forall d_1,\ldots,d_K,\quad
Y[d_1,\ldots,d_K] = WX[d_1,\ldots,d_K] + b.
$$

This is the generalization and may be confusing to read at first. The affine transformation happens at the _feature vector_ level. $D_1 \times \cdots \times D_K$ indexes a _specific_, $D$-dimensional feature vector of a specific unit of transformation, where each of $d^{(1)}, d^{(2)}, \ldots, d^{(D)}$ represents the value of a specific feature of the unit. A fully connected layer calculates the weighted sum of the values within this feature vector using a weight matrix $W$ of size $D' \times D$ (the linear combination) and adds a bias vector of dimensionality $D'$ (making the operation affine). It returns a new feature vector of dimensionality $D'$, indexed _exactly the same_ at $D_1 \times \cdots \times D_K$.

As an example, consider a batch of size $B$ of $D$-dimensional sequences of length $T$ each. Then, the batch is of size $B \times T \times D$. Each individual token of dimensionality $D$ identified by a specific $b$ and $t$ is transformed into a token of dimensionality $D'$. The output signal is of dimensionality $B \times T \times D'$. There is _no_ mixing _across_ feature vectors as long as the tensors are not flattened.

Then, it may initially seem that a fully connected layer is limited to creating _new_ views/interpretations of _existing_ features that are more useful to the task. The layer can however also reduce or increase the dimensionality of the feature vector ($D \ne D'$). The linear operation (dot product) can also be _interpreted_ as a matching/similarity score between two tensors. Their versatility makes fully connected layers the most used layers in deep learning.

# Convolutional layers
Fully connected layers have a minimal and extremely flexible inductive bias. They assume no locality importance/constraints and assume that every output feature can depend on any input feature. They also _ignore_ the spatial structure of the data. This provides considerable learning flexibility that makes these layers almost ubiquitous in deep learning architectures. A fully connected layer plays a _“do not assume much about the input signal and learn freely”_ card.

In theory, then, a fully connected layer can learn _any_ mapping. In practice, however, constraints such as those on compute and time necessitate layers with specific inductive biases. For example, the number of parameters and operations in a fully connected layer increases proportionally to the size of the input signal, which becomes prohibitively expensive quickly.

Convolutional layers apply affine transformations _locally_ to _patches_ of the input signal. Their inductive bias aligns with high dimensional input signals that exhibit _short-range correlations_, where features close to each other have similar properties, statistically and otherwise. These input signals typically exhibit _statistical stationarity_ in many operations. E.g. if pixels representing a cat are moved or translated from top-right to bottom-left in an image, they _still_ represent a cat. Similar stationarities apply to scaling (re-sizing) and symmetries (e.g. rotations). Convolutional layers build in inductive biases that leverage these statistical properties. A convolutional layer plays the _“assume the underlying data is strongly structured with significant, meaningful local patterns”_ card.

Take a $64 \times 64 \times 3$ RGB image. It has the spatial dimensions $64 \times 64$ across 3 channels, with each channel numerically encoding the representation of its respective color at each spatial location. Then, this image has 4096 pixels, and each pixel is a vector of length 3. A convolutional layer with 6 trainable _filters/kernels_ of spatial size $5 \times 5$ _convolves_ over this image and produces an output tensor of size $60 \times 60 \times 6$. It does so as follows: _each_ filter applies an affine transformation to a fragment of the image, or patch, of size $5 \times 5 \times 3$. Weights in the filter are linearly combined with the corresponding positions in the patch and then the bias is added in. The operation produces a $1 \times 1$ output. 6 filters performing the operation _independently but simultaneously_ on the patch stack their outputs to produce a $6 \times 1 \times 1$ tensor. The filters then move to the next patch and perform the same operation and stack the output, producing a $6 \times 2 \times 2$ tensor. The entire convolution operation, assuming no extra _stride_ or _padding_ (discussed later), produces a $6 \times 60 \times 60$ (or $60 \times 60 \times 6$) output tensor.

Several things become clear. First, a single affine operation with a filter always produces a scalar output, _regardless of filter size_. Second, each filter creates its _own_ channel/feature map. Third, the number of filters _equals_ the number of channels in the output. Fourth, the operation reduces (not always) the spatial dimensions in the resultant feature maps as compared to the input signal. It becomes apparent that each filter is a _detective_! _A specific filter uses individual affine operations to respond to the presence of a specific pattern at the specific input patch as a scalar and creates a feature map (channel) of these scalars by convolving across the entire input to respond to the presence of a specific pattern at patches across the input. Each filter completes this independently and creates its own feature map for its specific pattern. These feature maps are stacked to create an output signal that intuitively is a collection of each filter’s individual, independent attempt to identify specific pattern across the input at filter-sized patches. The convolutions may potentially reduce the size of the output. What each filter “looks for” is dynamic and optimized through learning (e.g. using gradient descent)._

A convolutional layer is _equivariant_ to translation: moving a pattern in the input also moves it similarly in the output. This is one of the primary inductive biases of a convolutional layer: it is equivariant to translation and thus suited for input signals that benefit from this bias (e.g. detecting a cat in images where the cat can be anywhere in an image).

There are also 3 additional hyperparameters:
- Padding
Padding ($p$) controls the number of 0-valued boundaries that are _artificially_ added around the input tensor. Padding allows for filters to extend beyond the input’s boundaries. This allows filters to analyze and interpret more “closely” the patterns around the edge of the input tensor (e.g. image). Convolutions will typically reduce the size of the output tensor vs the input, so padding also allows for maintaining the size of the input tensor throughout the architecture, or control it in general.
- Stride
Stride ($s$) controls the _step size_ of the filters as they convolve over the input signal. Larger strides correspond to a smaller output signal size and a coarser analysis of the input. A stride of 1 is the default and corresponds to the fine-grain analysis of the input.
- Dilation
Dilation ($d$) expands filter “view” by increasing the size of filters _without_ increasing the parameter count. A dilation of 2 on an image, for example, spaces out filter elements by a single pixel in all directions. The default is a dilation of 1 which corresponds to no spacing. As another example, a $3 \times 3$ convolution with a dilation of 2 still has 9 parameters. It however covers a $5 \times 5$ grid; the elements covered by the spaces are ignored. Dilation adjusts neither the input image (padding) nor the movement of the filter (stride), but the spacing of the filter.

As can be evident, the size of a convolution’s output is dependent on the hyperparameters of the convolution. In the case of no padding or dilation, a convolution with a kernel of size $K$ and stride $S$ on an input tensor of size $T$ outputs a tensor of size:

$$
\left\lfloor \frac{T-K}{S} \right\rfloor + 1
$$

Then, a 3-sized convolution with stride 1 on a 25-sized input and no padding or dilation outputs a:

$$
\left\lfloor \frac{25-3}{1} \right\rfloor + 1 = 23
$$

sized output tensor.

An activation in a deep architecture depends on a portion of the input fed into that layer, which in turn depends on a portion of the input fed into the preceding layer, and so on. This can be traced back to a portion of the _original_ input signal. The portion of the original input signal that a particular activation, _no matter where in the architectural pipeline_, depends on is called its _receptive field_. Due the compounded nature of a deep architecture, the receptive field is larger in coverage deeper in the network.

As an example, consider a neural network with an input image and multiple intermediate convolutional layers with filters of the same size. An activation in the first intermediate layer depends on a filter-sized patch of the input image. An activation in the second intermediate layer depends on a filter-sized patch of the first intermediate layer, _and each of the activations in that patch depend on their own filter-sized patches of the input image_. An activation in the second intermediate layer therefore depends on the entire region of the input image that produces the first-layer patch feeding into it. Then, receptive fields in successive convolutional layers capture a larger and larger portion of the input tensor, _indirectly_.

That they do so indirectly also has advantages. This expanding field of view enables the network to build _hierarchical representations_. Early layers, limited to small(er) receptive fields, may learn “simple” local features, while deeper layers may combine these patterns into increasingly complex structures. The network builds on compounded understanding; each layer has a “level” of understanding, which can be particularly useful in the identification of intermediate patterns (e.g. a fish within the broader image of a pond may be fully identified at an intermediate layer). An apparent disadvantage then is that convolutions build global understanding _slowly_ across _multiple_ layers.

Convolutional layers can be used to _recombine_ information and potentially reduce the size of the input tensor. This can result in a richer, more detailed representation of the input across a greater number of channels. Channels (or activation maps) can also be inferred as a _collection of the numerical responses to the presence of a specific pattern_. These layers are thus useful in use-cases such as object detection, matching exercises, or in general to map a higher-dimension input to a richer, lower-dimensional mapping.

There is also the transposed convolution operation that maps a lower dimension input to a higher dimension output. The details are beyond the scope of these learning notes.
