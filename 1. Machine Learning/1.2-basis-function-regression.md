# 1.2 Basis function regression

This one is interesting because it seems deceptively unimportant at first but is _crucial_ to understanding the transition into representation learning. At first glance, it seems a straightforward explanation of regression. Specifically, the basis function regression where non-linearity is introduced as additional features developed from the original input.

Consider a linear regression that is trained using the standard Mean Squared Error (MSE) loss. It takes the form of:
						ŷ = wx + b
where w is the trainable weight linear to the raw input feature x and b is the bias. Linearity to the raw variable captures only proportional change which limits the ability of a linear model to map complex relationships.

One way to introduce non-linearity here is to set up the prediction problem as a linear combination of non-linear representations of x:
						ŷ = Σᵢ wᵢφᵢ(x)
where φᵢ represents a basis function introducing a specific non-linearity in x.

The central idea is to increase the expressive power of a linear model by transforming the input through a collection of nonlinear basis functions and learning how to combine them. The basis functions themselves are fixed and chosen by the engineer. Each is a non-linearity that represents a different “lens” through which the model considers x, e.g. polynomial functions capture curvature. The final prediction becomes a learned, weighted combination of these non-linearities. This brings forth an important point: _the model is linear with respect to the weights and non-linear with respect to the input features themselves_.

Since the setup is non-linear in features but linear in the trainable weights it is modulated by, the key questions answered include: _how “much” does each of these non-linearities contribute to the prediction? Which “lenses” are the most important to look through? What is the relative importance in prediction for each of these pre-defined perspectives?_

Because the prediction is linear in the weights, the squared-error loss becomes a quadratic function of the parameters. Its gradient is therefore linear in the weights, and setting the gradient to zero produces a system of linear equations that can be solved directly. There exists a closed form solution.

Three key things emerge:
•	The setup remains unchanged except for the introduction of non-linear representations of x. The loss remains the MSE. Training remains either closed form or GD. The linearity with weights remains.
•	The non-linearities are chosen _in advance_. The model is restricted to expressing its solution in terms of a _pre-specified_ set of lenses. Trainable weights modulate relative importance of these lenses. _If the chosen functions do not match the true structure of the data, no amount of weight optimization can fully recover the missing representation_.
•	The setup seems significantly more powerful than a “linear-to-the-original-feature-only” setup but nevertheless limited in its ability to capture particularly intricate representations. _The difficult problem seems not only learning how to combine features, but discovering what features should exist in the first place_.

This naturally sets the transition into deep learning as two-fold: (1) representations – the lenses of looking at data – are very powerful, and (2) specifying them beforehand limits the ability of the model to learn. Deep learning allows for the representations to automatically emerge out of the training data. The neuron is set up as non-linear activation applied to an affine operation. Simple enough, but simplicity is _powerful_. Consider a neuron: ϕ(x) = σ(Wx+b).

The trainable weights are _within_ the basis function. Training determines _what_ each neuron becomes, what it _represents_. The weights learn the _projection of the input space_ on which the nonlinearity operates. In essence, the neuron is allowed, within architectural constraints, to _become or represent_ whatever it is needed to be to minimize the loss. Set up as layers, these neurons compose hierarchical representations that reach a level of abstraction far beyond what could possibly be designed manually in basis function regression.
