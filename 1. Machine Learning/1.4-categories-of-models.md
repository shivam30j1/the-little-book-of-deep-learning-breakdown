# 1.4 Categories of models

The chapter discusses three categories of models: regression, classification, and density modeling. The key ideas that emerge in this chapter include density modeling and the overlap across categories.
Regression consists of predicting a continuous value from an input signal. Formally, it finds a function f that maps the domain of input signals X to its codomain Y containing real-valued vectors of size K. It is a prediction problem where the value to be predicted is continuous in nature.

Classification is similar except Y consists of a finite number of values. The model predicts, given the input signal, a _score_ for each class. The setup maximizes the score for the correct class. The scores can be seen as a set of non-normalized probabilities across Y, with activation functions (sigmoid/softmax) being used to normalize these probabilities.

Both regression and classification are examples of supervised learning where the training data consists of pairs of input signal and _ground truth_ value.

Density modeling, given a dataset X, _models the probability density function of the data itself_. A pdf describes the distribution of probability density of a random variable over its possible values. This is _very_ powerful. Fundamentally, modeling a pdf allows not only for the plausibility of a particular sample under the learned distribution (as in the case of spam detection) but also _sampling_ from the same distribution. This technique can not only then be applied to problems such as spam/anomaly detection by modeling the pdf of non-spam emails and then predicting the density of unseen samples, but also generative problems where modeling the pdf allows for the sampling of _new, unseen_ samples (as in the case of diffusion models).

What is interesting is how blurred the distinctions between these categories are. For example, classification problems usually output logits, which are continuous values. Classification can therefore be viewed as a regression problem where the model predicts class scores. More interestingly, a density modeling exercise over a discrete sequence of tokens results in a joint probability distribution over all possible sequences. This is typically obtained using the chain rule, as a product of multiple conditional probability distributions. During inference, the next token's logits across the vocabulary are predicted using previously available or generated tokens. This is classification over the vocabulary at each step. Therefore, there is _significant overlap_ between these categories. There are also problems described in the book that fall within neither category, or simultaneously involve multiple categories.
