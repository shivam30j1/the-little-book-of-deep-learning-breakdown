# 3.4 Backpropogation

Gradient descent is one method to update a model’s parameters with respect to the loss by subtracting the gradient of the loss with respect to the parameters (modulated by a learning rate) from the parameters. The key challenge then is to _actually compute_ the gradients, particularly in deep models which are long compositions of mappings. The output of a neural network is the _activation_ of the final layer, which in turn depends on the activation of the immediately preceding layer, and so on. Specifically, a neural network computes a composite function f across D layers such that,

$$
f = f^{(D)} \circ f^{(D-1)} \circ \cdots \circ f^{(1)}.
$$

Each layer has its own vectors of activations and parameters, where an activation is calculated by modulating the incoming signal using the layer’s parameters and is then passed on as signal to the subsequent layer. This is the _forward pass_ of computation. Specifically, for an activation x at layer d,

$$
x^{(d)} = f^{(d)}[x^{(d-1)}; w^{(d)}].
$$

After the forward pass, the loss calculation determines how “well” the pass has done. To update the model’s parameters, the gradient vector must be calculated by computing the respective partial derivatives of the loss with respect to _all_ trainable parameters across _all_ layers, end-to-end. The network is a composition of mappings such that functions deeper in the network are composed entirely of those in the previous layers. The _chain rule_ of calculus then provides a way to calculate the derivative of the loss with respect to all parameters in all layers while providing immense computational efficiency _when applied backwards_. Formally, for a function f(m) where m = g(x) such that f(m) = f(g(x)),

$$
f'(x) = f'(g(x)) \cdot g'(x).
$$

The _outside_ function is differentiated while keeping the _inside_ function the same and this partial derivative is then multiplied by the derivative of the inside function. Now, consider the final output layer of a neural network that uses trainable parameters to calculate the final activation that then is used to compute the loss. To optimize the loss _with respect to_ the parameters, the derivative of the loss with respect to the parameters must be calculated. The input signal xn-1 is modulated by parameters w, resulting in the intermediate quantity z which then passed through a non-linearity outputs the final activation a. The loss l is computed as a function of the true output value y and activation a. The loss l then _depends on a which depends on z which depends on w_. Then, using the chain rule,

$$$\frac{dl}{dw} = \frac{dl}{da}\frac{da}{dz}\frac{dz}{dw}$$

The power of the chain rule becomes apparent as the pass moves back further into the network. Since weights in the penultimate layer connect to the loss through the final layer described above, _relevant partial derivatives of the final layer become outside functions in applying the chain rule to the penultimate layer_. These have _already_ been computed, their values are known, and they can be directly used. This results in significant computational efficiency. This is the backward pass of calculating the gradients. Combining the backward pass with the process of using the derivatives to run gradient descent to update the trainable parameters is called _backpropagation_. This is a _grossly simplified_ explanation and there may be many nuances in practice, but understanding the efficiency gains that come with promulgating the gradient backward instead of forward is important.

Modern deep learning frameworks in practice can automatically construct, under the hood, the chain of operations required for the forward pass as well as backpropagation. Autograd, for example, tracks operations during the forward pass as a Directed Acyclic Graph (DAG) and can dynamically compute gradients during the backward pass.

A point of confusion may be the concept of Jacobians. A Jacobian extends the concept of a gradient to _multiple_ outputs and inputs. In practice, quantities such as a, z, and w are tensors with multiple values. The underlying mathematical concepts remain identical; a Jacobian is simply a collection of gradients organized into a matrix to handle vector-valued mappings.

## Resource Usage

The _computational cost_ for the backward pass is usually greater than that of the forward pass, because the backward pass must compute gradient of the loss with respect to the weights through successive matrix multiplication per the chain rule. Forward passes usually perform fewer matrix multiplications.

The _memory requirement_ during the forward pass during inference is approximately equal to the size of the most demanding layer. Since activations from layers can be discarded after they have been promulgated during the forward pass, the memory must be able to fit the activations of the most demanding layer. During training, intermediate activations are _required_ for the backward pass to calculate and propagate the gradient backwards. This results in the memory requirement growing proportionally to the model’s depth. An important point is that the parameters must _also_ be stored in memory, so the above refers more to the _activation memory_ requirement. However, since the parameter footprint is constant for both inference and training, activation memory is the part that scales and varies.

Techniques exist to manage the memory requirement that the notes will not go deep in. These trade memory requirement for computational requirement. Examples include _checkpointing_, which stores only some activations (reduced memory requirement) and computes others on the fly (increased computational requirement). Examples also include reversible layers.

## Vanishing/Exploding Gradients

Backpropagation uses the chain rule to promulgate the gradient backward through the network. Since the network is (a) a long composition of mappings and (b) the Jacobians _“stack”_ progressively as the gradient moves further back through the layers, the gradient, calculated using the multiplicative process of the chain rule, can _explode_ to an astronomically large quantity or _vanish_ to a miniscule quantity.
For example, some partial derivatives are the parameter matrices (e.g. if h = Wx + b, then dh/dx = W). Improperly initialized weight matrices can lead to exponential changes in the gradient after multiplication, particularly as backpropagation runs deeper.

To mitigate exploding gradients, gradient norm clipping scales the gradient to maintain its _norm_ below a certain threshold when it moves above it. A norm, in this case, assigns a non-negative value to the gradient to denote its magnitude/size. The Euclidean distance is one type of norm frequently used and calculates the length of the vector. Then, rescaling the norm _reduces the length/magnitude but preserves the direction of the gradient vector_.

To mitigate the vanishing gradient is trickier and discussed later in the book. However, several techniques to mitigate the vanishing gradient focus on adapting the _architecture itself_ to the issue. Vanishing gradients lead to such miniscule values within the gradient that several parameters receive barely any to no updates. At worst, it makes training impossible. Instead of optimizing the algorithm further, the architecture of the network itself is adapted such that the _same_ optimization protocol is less prone to producing vanishing gradients. Another nod to how modularity becomes extremely powerful in deep learning.
