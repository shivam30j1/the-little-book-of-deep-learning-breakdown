# Chapter 3 - Training
Models are usually trained through minimizing a loss function, which represents a proxy for how *well* the model has *fit* the training data. In general, a smaller loss equals a better fit.

Loss minimization is the key (and sometimes the only) reference of fit. Since loss is a function of the trainable parameters of the model, mathematical and computational complexity for minimization increases as models themselves become more complex.

# 3.1 Losses
For density modeling, the objective is to maximize the likelihood of the *data itself*. Under the goal of modeling the probability distribution over the data, $p(x_n)$ can be interpreted as the probability density at sample $x_n$. The joint probability over the entire training set, then, equals $\prod_n p(x_n)$. This is the fundamental quantity to be optimized. Since addition is much easier to work with numerically than multiplication, the alternative optimization quantity becomes $\log \prod_n p(x_n)$, which equals $\sum_n \log p(x_n)$. This is equivalent to maximizing $\prod_n p(x_n)$ since $\log$ is *strictly increasing*. Now, neural networks actually rely on *minimizing* a loss. The loss function thus becomes the negation, $-\sum_n \log p(x_n)$. This is the *negative log-likelihood (NLL)* optimization function. Used also in, for example, logistic regression for classification, where the conditional probability $p(y\mid x)$ is optimized similarly.

### Cross-entropy
Cross-entropy (CE) loss is typically used for classification and is *very* similar to the NLL. As stated before, the optimization occurs for the *predicted* conditional probability $\hat{p}(y\mid x)$. A
classification problem outputs a vector of real numbers, with each corresponding to a possible class. These values can be *interpreted* as logarithms of non-normalized probability scores (*logits*), providing several benefits. A log is strictly increasing, which means higher logits strictly correspond to higher underlying scores. Logs also convert multiplicative relationships to additive ones. This is used to make computation easier in NLL. Here, it’s used *in reverse*: if the output is a logarithmic value, the underlying non-normalized value provides a *multiplicative* scale represented by the unbounded logit, giving it a meaningful *relative* magnitude. Exponentiation provides the non-normalized score. Dividing each exponentiated value by the sum of all exponentiated values provides a probability distribution summing to 1. This is the *softmax*.

The CE loss is $-\sum_n \log \hat{p}(y_n\mid x_n)$ for the correct class $y_n$, where

$$
\hat{p}(y_n\mid x_n)
=
\frac{e^{f(x_n;w)_{y_n}}}
{\sum_k e^{f(x_n;w)_k}}.
$$

Intuitively, it maximizes the likelihood of the correct class conditional on the input vector, across all examples. Technically, it is a simplified version of

$$
-\sum_n\sum_k q_{nk}\log \hat{p}_{nk},
$$

where $q$ is a one-hot encoded vector representing 0 for all classes and 1 for the correct class. Because $q$ selects only the correct class, the class summation collapses to $-\sum_n \log \hat{p}(y_n\mid x_n)$.
*Cross-*entropy because it weights the *surprise* of the prediction ($\hat{p}$ or $\log\hat{p}$) using the true distribution ($q$). The higher the probability, the lower the *surprise*. Hence the negation. And the usual benefits of log transformation inspire the log probabilities.

## Contrastive Loss
Certain situations require the *prediction* of continuous values but the *evaluation* of constraints or contrasts. Such situations enforce ranking through a *contrastive* loss. For example, a case of metric learning where the goal is to predict distance between examples such that the distance between any two examples of the same class (e.g. photo of a person) is less than that between two examples of different classes. This objective is enforced through a contrastive loss where, for a triplet $(x_a,x_b,x_c)$, $f(x_a,x_b)$ is smaller than $f(x_a,x_c)$ by a prespecified margin. Assuming $x_a$ and $x_b$ belong to the same class, the model will *not* treat them as such unless the predicted distance between them is smaller than that between $x_a$ and $x_c$ by a prespecified margin. This is enforced through the contrastive loss

$$
\max(0,\;m-f(x_a,x_c;w)+f(x_a,x_b;w)),
$$

which can also be written as

$$
\max(0,\;m-[f(x_a,x_c;w)-f(x_a,x_b;w)]).
$$

$[f(x_a,x_c;w)-f(x_a,x_b;w)]$ evaluating to greater than $m$ causes the loss contribution for that specific example to be 0. If the gap is less than $m$, the loss is positive and equals the *shortfall* from $m$. In the book, $m=1$.
